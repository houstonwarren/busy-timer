# Agent Notes

SwiftUI iOS app: a fixed 20-minute burpee timer. Sources in `busy-timer/busy-timer/`, unit tests in `busy-timer/busy-timerTests/`.

## Commands

- `just test` — unit tests on the newest iPhone 17 Pro Max simulator; run after any change
- `just run` — build and launch in that simulator
- `just run-iphone` — build, install, and launch on a connected iPhone (must be unlocked with Developer Mode on)
